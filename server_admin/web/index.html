서버별 트래픽 설정

가중치는 정상이며 트래픽이 허용된 서버끼리의 상대 비율입니다.

i
장애와 작업 제외를 구분합니다.장애 서버는 우회하며, 점검으로 제외한 서버는 관리자가 복귀해야 요청을 받습니다.

인물 연결 민감도

저장 대상: vault.person · 기존 PID끼리는 합치지 않습니다. 선택한 기준으로 신규 정보를 기존 PID에 연결합니다.

이름만 일치하거나 주소만 같은 경우에는 연결하지 않습니다. 주민번호·전화번호 충돌, 복수 후보, 기록된 역할 충돌은 모든 설정에서 보류합니다. 기존 DB에 역할 이력이 없으면 고객·직원을 완전히 구별할 수 없습니다.

문서처리PID / 후보판단 근거가명 정보

미리보기는 DB를 변경하지 않습니다. 민감도는 이번 실행에만 적용됩니다. 서버 기본값은 PID_SENSITIVITY로 설정합니다. DB·원문·정책이 바뀌면 미리보기를 다시 해야 합니다. 원문이나 비밀키는 화면에 표시하지 않습니다.

서버별 요청 현황

분산기를 거친 요청만 셉니다. 기록에는 시각·서버·데이터 버전·종류·응답 코드·걸린 시간만 남고 질문 내용과 사용자 정보는 없습니다. 10초마다 새로 고칩니다.
